## Introduction

Yunbei Urban Construction is a Minecraft mod focused on city building, providing a variety of road blocks, traffic facilities, signs, barriers, and more. The mod enriches urban construction gameplay and supports data generation and custom extensions.

## Download

Visit the [Modrinth project page](https://modrinth.com/mod/yunbeiuc) to download the latest version.

**Supported Minecraft Versions:** 1.20.1  
**Dependencies:** Fabric API, Geckolib4
