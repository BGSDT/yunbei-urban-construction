## 简介

云北城建是一个面向 Minecraft 的城市建设模组，致力于丰富城市道路、交通设施、标志牌等内容，提升游戏内城市建造体验。模组包含多种道路方块、实体、标志牌、护栏等，支持数据生成与自定义扩展。
